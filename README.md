# ECON 50803 — Environnement macroéconomique

Dans les documents du MBA, les sessions s’écrivent en toutes lettres, par exemple « Hiver 2026 » ou « Automne 2026 ». Les noms de fichiers utilisent la première lettre de la session et les quatre chiffres de l’année.

| Document | Emplacement et nom |
| --- | --- |
| Examen final d’automne | `Evaluations/A2026/Final/final_A2026.pdf` |
| Quiz d’hiver avec solutions | `Evaluations/H2026/Quiz/quiz_H2026_solutions.pdf` |
| Projet de session d’automne | `Project/projet_session_A2026.pdf` |
| Diapositives communes aux sessions | `Slides/S3/s3.pdf` |
| Exercices de la même séance | `Exercices/exercices_s3.pdf` et `Exercices/exercices_s3_solutions.pdf` |

Le sujet et sa source LaTeX portent le même nom de base. Le suffixe `_solutions` désigne le corrigé. Les évaluations sont conservées localement. Les titres de séance sur les couvertures des exercices reprennent ceux des diapositives.
